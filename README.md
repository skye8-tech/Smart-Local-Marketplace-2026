## Project Description

Smart Local Marketplace is a web-based platform that helps local sellers and customers connect in one organized digital environment. Customers can browse, search, filter, and order local products. Sellers can register, manage product listings, and use a dashboard. Administrators can verify sellers and monitor marketplace activity.

---

## Problem Being Solved

Many local sellers still rely on physical stores, social media, and word-of-mouth. Customers often struggle to:

- Discover products from different local sellers
- Compare options easily
- Place organized orders
- Find nearby sellers

This project provides a simple, centralized marketplace focused on local product discovery and ordering.

## How to Use

1. Open the homepage
2. Browse categories or search for products
3. View product details and add items to cart
4. Proceed to checkout and submit an order
5. Sellers can register and manage products
6. Admins can verify sellers and monitor orders

---

## Limitations (Prototype)

- Uses browser LocalStorage (not multi-user)
- No real backend or database
- Payment is method selection only
- No full authentication system yet
